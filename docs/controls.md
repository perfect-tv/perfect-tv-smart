# Управление и навигация

Эталон раскладки. Меняется раскладка — обновить этот файл и окно «Управление» (`HelpLayer` в `ui/popups.ts`, строки — в `strings/*.json`).

## Клавиши пульта

Клавиши идут в `Tv` через обработчик `keydown`/`keyup` на документе, мимо фокуса браузера (кроме полей ввода форм). Разбирает `ui/keys.ts`, верхний слой стека (`Layer`) получает имя клавиши.

| Коды (пульт LG / клавиатура) | Имя |
|---|---|
| 37–40 (←↑→↓) | left, up, right, down |
| 13 (OK, Enter) | OK |
| 461 («Назад»), 27 (Esc), 8 (Backspace) | Назад |
| 33 / 34 (CH+ / CH−, PageUp / PageDown) | PG+ / PG− |
| 48–57, 96–105 | цифры |
| 415 ▶, 19 ⏸, 413 ⏹, 412 ⏪, 417 ⏩; пробел — ⏯ | play, pause, stop, rewind, forward, playpause |
| 458 GUIDE (G), 457 INFO (I) | гид, инфопанель |
| 403 красная (M) | меню канала (кнопки «Меню» у пульта LG нет — система её не отдаёт) |
| 404 зелёная (H) | недавние каналы |
| 405 жёлтая | напоминания |
| 406 синяя (F) | поиск |

**Magic Remote.** Пока виден курсор — работают щелчки (канал, передача, пункт меню, кнопка окна; щелчок мимо окна — закрыть) и колесо (каналы в гиде и плеере, пункты в списках, прокрутка окон; в сетке гида горизонтальная прокрутка — время). Правый щелчок в гиде — меню канала. Стрелки скрывают курсор.

## Долгие нажатия и удержание

- Если у верхнего слоя для клавиши есть долгое действие (`hasLong(name)`), короткое срабатывает на **keyup**, а долгое — через 500 мс удержания (`Keys.LONG_PRESS`). Если долгого нет — сразу на keydown.
- OK: короткое — на keyup, долгое — 800 мс (`OK_LONG_PRESS`). красная — сразу меню канала.
- После долгого нажатия автоповтор этой клавиши игнорируется до keyup, даже если экран сменил режим (гид → сетка).
- Удержание ↑/↓ в списках листает своим таймером, а не автоповтором системы: старт через 350 мс, шаг с ускорением от ~11 до ~28 строк в секунду за 1,5 с, до keyup. Интервал считается без времени обработки шага.
- Слой может запретить повтор (`holdRepeat = false`): в окне PIN удержание стрелки не набирает цифры подряд.

## Плеер (нет открытых окон)

| Кнопка | Эфир | Архив |
|---|---|---|
| ← / → | предыдущий / следующий канал категории (задержка 0,7 с, видна инфопанель и карусель) | перемотка −/+: нажатие — 30 с, удержание — быстрее с каждой секундой (от 30 с до 10 мин эфира в секунду); применяется через 0,9 с после отпускания |
| ↑ | развёрнуто описание — свернуть; показанная инфопанель (закреплённая или ещё не скрывшаяся после смены канала / перемотки) — закрыть; иначе «Программа и архив» канала (или «Недавние каналы» — настройка «Клавиша ↑ в плеере») | то же |
| ↓ | инфопанель **без автоскрытия** (закреплена); повторно — развернуть под ней описание передачи (баннер TMDB или логотип канала); если панель уже на экране (показана по таймеру после смены канала) — сразу закрепляется и разворачивается | то же |
| OK | ТВ-гид; набирается номер — переключить; инфопанель на экране (закреплённая или показанная по таймеру) — пауза / продолжить; идёт перемотка — применить её сразу | то же |
| удерж. OK, красная | меню канала | то же |
| удерж. ↓ | недавние каналы | то же |
| удерж. ↑ | напоминания | то же |
| PG+ / PG− | следующий / предыдущий канал категории | то же |
| 0–9 | номер канала: слева вверху — набранный номер, логотип и название, ниже — подсказки (каналы, которые выберутся следующей цифрой); переключение через 2 с или сразу, если следующая цифра невозможна | то же |
| ⏯ / ▶ / ⏸ | пауза / продолжить (эфир после паузы — со сдвигом) | то же |
| ⏪ / ⏩ | перемотка; из эфира — уход в архив, если он есть | перемотка |
| ⏹ | как «Назад» для выхода | вернуться в эфир |
| Назад | отмена набора номера / перемотки → свернуть описание → закрыть закреплённую инфопанель → тост «нажмите ещё раз»; второе «Назад» в течение 2 с — выход | то же |

**Назад ×2 на закрытом канале.** Если играет канал, закрытый PIN, второе «Назад» не закрывает приложение: включается последний незаблокированный канал (тот, что играл перед закрытыми; если его нет — первый незаблокированный из недавних), список недавних каналов возвращается к тому, каким был до закрытых, и PIN снова нужен. Тост первого «Назад» — «…к последнему открытому каналу».

**Карусель.** При ←/→ и PG± над инфопанелью — лента карточек категории (логотип, под ним название), выбранная по центру в белой рамке; лента сдвигается на карточку за нажатие. Каналов меньше, чем карточек, — повторяются по кругу; единственный канал — одна карточка. Скрывается через 1,5 с после переключения или вместе с инфопанелью.

**Инфопанель.** Показанная сама (переключение, перемотка) скрывается через «Скрывать инфопанель через». Открытая ↓ — закреплена: остаётся до ↑ или «Назад», переключение каналов её не открепляет; внизу закреплённой — строка подсказок клавиш для текущего состояния (настройка «Подсказки клавиш»). Описание (↓↓) выдвигается по высоте за 0,25 с под разделительной полосой: картинка, описание и «Далее на канале». При перемотке вместо строки «Далее» — пузырь с целевым временем под маркером шкалы.

**Пауза эфира.** Позиция запоминается в реальном времени. После продолжения поток играет из буфера со сдвигом (бейдж «Архив», «−0:45»), ←/→ перематывают (если у канала есть архив). Не удержал сдвиг — новая ссылка архива на нужный момент; без архива — эфир.

**Закрытые каналы при листании.** ←/→ (PG±) попали на закрытый канал — окно PIN; отмена — включается следующий в ту же сторону канал, для которого PIN не нужен (закрытые пропускаются). Из закрытого канала, открытого по PIN, в другой закрытый — без PIN (пока не включили открытый канал или не заблокировали текущий во время просмотра).

## ТВ-гид, фокус на списке каналов

Категории: «Избранное» (если не пусто), «Все каналы» (все видимые каналы в порядке плейлиста; не скрывается и не блокируется), затем категории плейлиста.

| Кнопка | Действие |
|---|---|
| ↑ / ↓ | канал (по кругу), удержание — быстро |
| PG+ / PG− | на страницу |
| ← | колонка категорий (см. ниже) |
| → | фокус в сетку программы; в видах со списком программы — в список передач канала |
| удерж. ← | «Программа и архив» канала (только в таблице; в виде «Список» программа канала всегда справа — удержания нет, окно — в меню канала) |
| OK | смотреть канал и закрыть гид |
| удерж. OK, красная | меню канала |
| 0–9 | перейти к каналу по номеру |
| Назад | закрыть гид (без видео — запрос выхода) |

Внизу гида — строка подсказок клавиш для текущей зоны (настройка «Подсказки клавиш»); с ней на экране 9 каналов, без неё — 10.

## ТВ-гид, виды «Категории + каналы» и «Каналы»

Настройка «Вид гида» (и пункт «Вид» в меню канала → «Список каналов») — четыре вида: «ТВ-гид» (сетка), «Каналы + программа» (ниже, «вид «Список»»), «Категории + каналы», «Каналы».

В двух последних **правая часть экрана не затемнена** — видно видео; затемнение слева плавно (градиентом) уходит в прозрачное, под шапкой — своё мягкое затемнение сверху. Программа канала появляется только по →:
- **«Категории + каналы»:** категории и каналы на экране сразу. ← из каналов просто переводит фокус в колонку категорий (там ↑ / ↓ — категория, → / OK — к каналам, ← — плейлисты, как обычно); → из каналов — категории уезжают влево, из-под списка каналов выезжает программа канала с фокусом на идущей передаче, экран затемняется целиком; ← из программы — она схлопывается, категории выезжают обратно.
- **«Каналы»:** на экране только каналы; ← выдвигает категории со сдвигом экрана (левее — плейлисты), → — программа выезжает из-под списка.

Программа, даты, панель «Описание в ТВ-гиде» и шапка работают в них так же, как в «Каналы + программа».

## ТВ-гид, вид «Каналы + программа» (бывший «Список»)

Три колонки: каналы (без таймлайна, как в таблице), **программа канала в фокусе** (передачи от начала архива до недели вперёд; идущая — подсветка, LIVE и шкала прогресса, прошедшая в пределах архива — значок архива, будущая с напоминанием — значок часов) и **компактные даты** (день недели и число). Листаешь каналы — список справа сразу меняется, на нём — идущая передача.

| Где фокус | Кнопка | Действие |
|---|---|---|
| Каналы | → | в список передач (на идущей); ← — категории; OK — смотреть; удерж. OK — меню канала |
| Передачи | ↑ / ↓, PG± | передача |
| | OK | идёт — смотреть эфир; прошла и есть архив — из архива; иначе — карточка передачи |
| | удерж. OK | карточка передачи |
| | ← / → | к каналам / на даты; Назад — к каналам |
| Даты | ↑ / ↓ | день (список уходит на его первую передачу или идущую) |
| | ← / OK | к передачам; Назад — к каналам |

**Настройки гида** (раздел «Внешний вид»):
- «Шапка гида» — «Канал + передача» (логотип, канал, название, время, описание передачи в фокусе; по умолчанию), «Канал» (логотип, название, категория, глубина архива, часы) или «Скрыть» (шапки нет, каналов на экране больше). Действует и в таблице, и в списке.
- «Описание в ТВ-гиде» (только вид «Список»; по умолчанию выкл.): при переходе в передачи список каналов сжимается до колонки логотипов, шапка — до «Канал», справа выезжает панель передачи (картинка из EPG или логотип канала, время, название, описание, что сделает OK). ← к каналам разворачивает каналы и убирает панель; удерж. OK на колонке логотипов — меню канала. Работает одинаково при любой шапке.

## ТВ-гид, колонка категорий (← из списка каналов)

Колонка выезжает слева, а список каналов и сетка сдвигаются вправо — правая часть сетки уходит за край экрана. Шапка с передачей и часами остаётся на месте. В колонке — название, число каналов, у заблокированных — замок, у «Избранного» — сердце.

| Кнопка | Действие |
|---|---|
| ↑ / ↓ | категория (по кругу, удержание — быстро); список каналов справа меняется сразу; канал — тот же, если он есть в категории, иначе первый |
| PG+ / PG− | на страницу |
| → / OK | к каналам выбранной категории, колонка уезжает |
| Назад | отмена: категория и канал — как до открытия колонки |
| удерж. OK, красная | меню канала |

Над категориями — строка «Поиск»: ↑ с первой категории — на неё (ещё ↑ — к последней категории), OK — открыть поиск.

**Плейлисты.** ← в колонке категорий (если плейлистов больше одного) выдвигает левее ещё одну колонку — **плейлисты** (название и число каналов; открытый сейчас выделен): экран сдвигается тем же образом, категории остаются между плейлистами и каналами. ↑ / ↓ — плейлист, OK — открыть его (другой плейлист — перезагрузка гида; тот же — назад к категориям), → или Назад — к категориям.

## ТВ-гид, фокус в сетке

Окно 2 ч, шаг 30 мин, линия «сейчас» на 25% ширины; пока фокус в списке каналов, окно «живое» (сдвигается со временем). Пустые получасовые слоты — без программы.

| Кнопка | Действие |
|---|---|
| ← / → | предыдущая / следующая передача, окно времени сдвигается |
| ↑ / ↓ | канал выше / ниже, время сохраняется |
| OK | карточка передачи |
| Назад | к списку каналов (время — на «сейчас») |

## Программа и архив (↑ в плеере, удерж. ← в таблице гида, меню канала)

Передачи канала от старых к новым: прошедшие — только в глубине архива (`catchup-days` N — ровно последние N × 24 ч: при одном дне в 23:00 список начинается с передачи, что шла вчера в 23:00; без архива — с начала сегодняшних суток, прошедшие без значка архива: их видно, но отмотать на них нельзя), в архиве — со значком архива; где программы нет — «Нет программы» по 30 минут (или до ближайшей передачи), даты архива есть всегда. Затем текущая (▶ LIVE, под названием — шкала), будущие. Слева — вкладки дат, справа от списка — панель передачи в фокусе (время, название, описание, внизу — что сделает OK). В шапке окна справа — кнопки «Программа» и «Напоминания · N» (N — число напоминаний). Удерж. ↑ в плеере и «Напоминания» в меню открывают окно сразу на вкладке напоминаний.

Подсветка: белая заливка — только фокус (передача в списке, вкладка даты или кнопка вида); рамкой — то, куда перейдёт фокус: пока он в списке — дата этой передачи (при ← рамка заполняется белым), пока на датах — передача выбранного дня, на которую он встанет по → (первая, а если в этом дне есть играющая — она). Серым — только передача, которая играет, и её дата (всегда), и кнопка открытого вида в шапке.

| Кнопка | Действие |
|---|---|
| ↑ / ↓ | передача (удержание — быстро), PG± — на страницу |
| ← | к вкладкам дат (слева): ↑/↓ — день (список прокручивается к заголовку), → / OK / Назад — обратно в список (на первую передачу дня, а если в нём играющая — на неё) |
| → | к кнопкам «Программа» / «Напоминания» в шапке: ← / → — соседняя кнопка (список меняется сразу), ↓ / OK / Назад — обратно в список; ← с первой кнопки — тоже в список |
| OK | прошедшая в архиве — смотреть из архива; текущая — эфир; будущая или прошедшая без архива — карточка |
| удерж. OK | карточка передачи («Смотреть с начала», «Напомнить») |
| Назад | закрыть |

## Карточка передачи

←/→ — кнопки, ↑/↓ — прокрутка описания, OK — действие, Назад — закрыть. Кнопки:

- прошедшая в пределах архива — «Смотреть»;
- текущая — «Смотреть с начала» (если есть архив), а также «Смотреть эфир» (если этот канал сейчас в архиве) или «Смотреть» (если канал другой);
- будущая — «Напомнить» или «Удалить напоминание».

## Меню канала (удерж. OK, красная)

Шторка справа: видео и инфопанель остаются видны. Сверху — до четырёх **плиток** частых действий, фокус сразу на первой; ниже — три группы пунктов. Всё помещается без прокрутки.

- **Плитки** (по убыванию важности, первые четыре): «Смотреть» (из гида), «В эфир» (идёт архив), «С начала» (есть архив и передача), «Программа» (окно «Программа и архив»), «В избранное» / «Из избранного», «Недавние». Что не поместилось — первыми пунктами «Просмотра».
- **Просмотр**: «О передаче», «Звук и субтитры» › (если звуковых дорожек больше одной или есть субтитры), «Формат кадра» (авто / растянуть / увеличить), «Таймер сна» (выкл. / 15 / 30 / 45 / 60 / 90 / 120 мин).
- **Канал**: в категории «Избранное» — «Выше» / «Ниже»; «Скрыть канал», «Заблокировать / Разблокировать канал», «Категория „…“» › («Скрыть категорию», «Заблокировать / Разблокировать категорию»).
- **Приложение**: «ТВ-гид» (из плеера), «Напоминания», «Список каналов» › («Вид», «Адаптивная сортировка», «Скрытое»), «Плейлист и программа» › («Плейлист», если их несколько, «Обновить плейлист», «Обновить программу»), «Управление», «Настройки».

| Кнопка | Действие |
|---|---|
| ↑ / ↓ | пункт (по кругу, через ряд плиток); удержание — быстро |
| ← / → | в ряду плиток — плитка; на пункте с «›» → открывает страницу; на странице второго уровня ← — обратно |
| OK | выполнить (меню закрывается); «Формат кадра», «Таймер сна», «Вид», «Адаптивная сортировка», выбор дорожки меняются на месте |
| Назад | со страницы второго уровня — обратно на тот же пункт, иначе закрыть |
| красная | закрыть |

**Звук и субтитры.** Дорожки текущего потока; играющая отмечена «●». Выбранный язык запоминается и предпочитается на других каналах. Субтитры «Выкл.» действуют до выбора дорожки.

**Таймер сна.** OK по пункту — следующее значение. За минуту до срабатывания — тост, по сроку приложение закрывается. Таймер сбрасывается при выходе из приложения.

Скрыли канал или категорию — фокус гида встаёт на соседний канал / категорию (предыдущий, нет — следующий), а не на первую категорию.

## Поиск (меню канала → «Поиск», строка «Поиск» над категориями в гиде, кнопка поиска на пульте)

Во весь экран поверх плеера или гида. Слева — поле запроса, клавиатура и под ней «Запросы»; справа — результаты: каналы (без скрытых), «Сейчас в эфире», «Скоро» (на неделю вперёд), «В архиве» (в пределах архива канала). Каналы ищутся сразу, передачи — по названию, через 0,3 с после набора (от двух букв); несколько слов — должны встретиться все.

| Где фокус | Клавиша | Действие |
|---|---|---|
| Клавиатура | ← ↑ ↓ → | соседняя клавиша; → с правого края — результаты, ↓ с нижнего ряда — запросы |
| | OK | ввести; `#&` — символы, `EN` / `RU` — язык, ⌫ — стереть |
| | удерж. OK на ⌫ | очистить поле |
| | 0–9 на пульте | цифра в запрос |
| | Назад | закрыть поиск |
| Запросы | ↑ / ↓ | запрос; ↑ с первого — клавиатура; → — результаты |
| | OK | подставить запрос в поле |
| | удерж. OK | убрать недавний запрос (у подсказок — ничего) |
| Результаты | ↑ / ↓, PG± | находка |
| | OK | канал или передача в эфире — смотреть; передача из архива — с её начала; будущая — карточка передачи («Напомнить») |
| | удерж. OK | «Программа и архив» канала |
| | ←, Назад | к клавиатуре |

Клавиатура — сетка 11 × 5: три ряда букв (ЙЦУКЕН / QWERTY или по алфавиту — настройка «Раскладка клавиатуры поиска»), ряд цифр (одинаков во всех раскладках) и служебный ряд. В символах — куски адреса (`http://`, `https://`, `.m3u8`, `.xml.gz`). Клавиша, с которой фокус ушёл в запросы или результаты, остаётся в рамке.

«Запросы»: недавние (значок часов; запоминается запрос, по находке которого нажали OK, до 8 штук) и подсказки из найденных названий (лупа), всего до пяти.

## Недавние каналы

↑/↓ — выбор, OK — запустить, удерж. OK — меню канала, Назад — закрыть.

## Напоминания

- **Добавить**: «Напомнить» в карточке будущей передачи. Запланированные отмечены значком часов (окно программы, ячейки сетки).
- **Список**: удерж. ↑ в плеере, меню канала → «Напоминания», → из окна программы (кнопка в шапке).
- **Показ**: за N минут до начала (настройка «Напоминать о передаче») — окно: канал, «Напоминание · через 5м» / «уже идёт», время, название, описание; кнопки «Смотреть» (в фокусе), «Отложить на 5 мин», «Закрыть». Пропущенная передача с архивом — «Смотреть из архива», «Позже» (остаётся в списке до конца архива), «Удалить».
- Несколько сразу — одно окно со счётчиком «1 / 3»: ↑/↓ — другие, «Закрыть все». Новые добавляются в то же окно, текущее не меняется, пока пользователь не листал.
- Приложение закрыто — напоминаний нет: у веб-приложения webOS нет фоновых задач. При запуске пропущенные с архивом всплывают окном «Пропущено».

## Окно PIN

PIN — 4–6 цифр, видны только набранные точки по центру (длина не видна). Цифры пульта работают всегда. «Назад» стирает цифру, на пустом поле — отмена. PIN принимается, как только набран верный; набрано 6 и не совпало — «Неверный PIN». Способ ввода — настройка «Ввод PIN»:

- **Кольцо** (как Fire TV): ↑ → ↓ ← = 1 2 3 4, OK = 0; красная или удерж. OK — раскладка 5–9: ↑ → ↓ ← = 5 6 7 8, OK = 9.
- **Ряды** (как Google): ряд 1·2·3 — ← = 1, OK = 2, → = 3; ↑/↓ — другой ряд (с 1·2·3 вверх — на 7·8·9); на ряду 7·8·9 ↓ = 0 (рамка буквой «Т» обводит ряд и 0). Справа — все цифры с выделенным рядом.
- **Клавиатура**: сетка 1–9, ⌫, 0, «Готово», стрелки по кнопкам.

В кольце и рядах нажатая цифра не подсвечивается. Создание PIN — всегда клавиатурой, ввод дважды.

## Окно «Управление»

Меню канала → «Управление». Кнопки по разделам; ↑/↓ — прокрутка, PG± — на страницу, OK/Назад — закрыть.

## Скрытое, блокировка, адаптивная сортировка

- **Скрыть** канал или категорию — из меню канала. Скрытое не показывается нигде (гид, карусель, «Все каналы», номера). Вернуть: «Скрытое» в меню или Настройки → «Скрытые категории и каналы» (все плейлисты).
- **Заблокировать** канал или категорию — по PIN (при первой блокировке PIN задаётся). Заблокированный помечен замком; переход на него спрашивает PIN (настройка «Спрашивать PIN»: каждый раз / один раз до выхода). Снятие — тоже по PIN.
- **Адаптивная сортировка**: канал, который смотрели дольше 5 минут подряд, получает +1; в категориях каналы идут по очкам, при равенстве — по номеру. Порядок меняется при следующем открытии гида, а не на глазах. Избранное сохраняет ручной порядок. Сброс очков — в настройках.
