# AGENTS.md — Perfect TV для LG webOS

Документация и комментарии — на русском. Проект самостоятельный: поведение и вид описаны в `docs/` — ТЗ (`docs/TZ.md`), управление (`docs/controls.md`), оформление (`docs/design.md`), план и что проверено (`docs/PLAN.md`). Чего там нет — решить и дописать туда же.

## Команды

- `npm run build` — сборка в `dist/` (ES5, проверка парсером); `npm run dev` — то же с пересборкой при изменениях.
- `npm test` — юнит-тесты (vitest): M3U, XMLTV, шаблоны архива, сопоставление, клавиши, ячейки, строки.
- `npm run typecheck` — проверка типов.
- `npm run proxy` — локальный прокси на ПК (для браузера и симулятора).
- `npm run package` — `.ipk` в `out/`.
- `npm run installer` — установщик на ТВ для людей: `out/PerfectTV-Installer-<версия>.zip` (Windows `.exe` + `.ipk` + инструкция; исходник — `tools/tv-installer`, Go 1.21+).

## Правила

1. **Только ES5 после сборки.** Минимум — webOS 3 (Chromium 38). Синтаксис пишем современный (его переводит tsc), но библиотечные функции новее Chromium 38 — только с полифилом в `core/polyfills.ts`. Нет `fetch`-потоков, CSS-переменных, `Object.assign` (полифил есть), `Array.prototype.includes` (полифил есть), `URL`, `AbortController`. Наследование от `Error` — с `Object.setPrototypeOf` (см. `NetError`).
2. **Плейлист и программа — только потоком** (`Net.stream` → `Unpacker` → `M3uParser` / `XmltvParser`). Файл целиком в память не читать; программу писать пачками по каналу.
3. **Время** — `Clock.now()` (unix-секунды с поправкой по серверу), не `Date.now()` (кроме таймеров интерфейса).
4. **Интерфейс без фреймворков.** Окна — DOM (`ui/popups.ts`, классы из `ui/style.ts`), гид — команды рисования Canvas 2D (`ui/guide.ts`), которые по настройке «Отрисовка гида» идут либо в DOM (`ui/domctx.ts`, по умолчанию: элементы из постоянного набора, меняется только изменившееся), либо в `<canvas>`. Новое рисование в гиде — только тем, что умеет `DomCtx` (прямоугольники, `roundRect`/`strokeRoundRect`, текст, картинки, линии, `drawIcon`, обрезка прямоугольником, `translate`, `globalAlpha`), и проверять в обоих режимах. Размеры — в rem (1 rem = 1 em = высота / 48), цвета — `C` из `ui/u.ts`. Фокус — класс `f` (белый фон, чёрный текст), фокус браузера не используется.
5. **Клавиши** — через `Keys` и `Layer` (`ui/keys.ts`, `ui/layer.ts`). Раскладку менять вместе с `docs/controls.md` и окном «Управление» (`HelpLayer`).
6. Пользовательские данные привязаны к ключу канала `Names.key(name)`, а не к номеру.
7. **Строки — только `strings/<код>.json`** (`en` — основа, `ru` — поддерживается вместе с кодом, остальные языки — переводы, регистрация в `src/core/langs.ts`): `str('ключ', …)`, счётные — `plural`. Новый ключ — в `en` и `ru` (тест `lang.test.ts`); другие языки возьмут английский, пока не переведут (`npm run i18n`). Строки не кэшировать в полях модулей — язык меняется на ходу. Перевод — `docs/translating.md`.
8. Сеть приложения — через `Net` (прокси при заголовках канала и CORS). `service/proxy.js` — ES5 и только модули Node (на webOS 3 в сервисе Node 0.12).

## Тонкости

- **Архив Flussonic.** Передача моложе 6 ч — `archive-START-now.m3u8` (EVENT), старше — `archive-START-DURATION.m3u8`. `?event=true` не использовать: балансировщики отбрасывают параметры. hls.js стартует архив с `startPosition: 0`, время кадра — `fragment.programDateTime` (`Playback.wallClockMs`); `Tv.onReady` ставит позицию на начало передачи, если плеер начал не там.
- **CORS.** Упакованное приложение (`file://`) не получает ответы серверов без CORS и не может ставить `User-Agent`/`Referer`. Прокси переписывает адреса внутри `.m3u8`, чтобы сегменты шли с теми же заголовками.
- **Симулятор** JS-сервисы не запускает: для проверки в нём держать `npm run proxy` на ПК — приложение найдёт прокси на `127.0.0.1:47380`.
- **«Назад»** — код 461, приходит только при `"disableBackHistoryAPI": true` в `appinfo.json`.
- **Magic Remote**: курсор — события мыши, `cursorStateChange`; колесо — `wheel`.
- **С 1.0.9 настройки/история/избранное сохраняются в отдельной SQLite3 (`service/sqlite-settings.js`), чтобы запись последнего канала не пересобирала большую EPG; старые настройки копируются при первом старте. Программа загружается и разбирается в Node-сервисе** (`service/epgservice.js`): HTTP/XMLTV/gzip/zip, сопоставление и пакетная запись в SQLite. Браузер через `data/epgservice.ts` получает по WebSocket только прогресс и метаданные; обычный браузерный EPG Worker из 1.0.7 не запускается. `src/service/epg-entry.ts` компилируется в ES5 CommonJS `service/epg-parser.js` для использования того же XMLTV-парсера и matcher, что в TypeScript. Сервисное приложение не должно импортировать DOM.
- **webOS 3.** В `appinfo.json` не ставить пустые `requiredPermissions` / `requiredACG`: на webOS 3 приложению тогда запрещён вызов своего же сервиса («Denied method call … for category "/"»). Origin приложения там — `file://top.rootu.perfecttv` (на webOS 4+ — `file://` / `null`), проверки Origin в сервисе принимают оба. У JS-сервиса webOS 3 нет прав на `/media/internal` — папку данных выбирает `service/datadir.js` (первая доступная на запись, видна в ответе `ping`). Проверять на эмуляторах — README, «Эмуляторы webOS TV 3 и 4».
- **Журнал** (`core/log.ts`) — первое, что смотреть, когда на ТВ что-то не так.

## Перед завершением

`npm run typecheck && npm test && npm run build`. Изменения интерфейса — проверить в браузере 1920×1080 или симуляторе (снимок экрана).

## Хранилище (с 1.1.0)

Данные приложения хранит JS-сервис в файлах (`service/filekv.js`), интерфейс обращается к нему по WebSocket `ws://127.0.0.1:47380/db` (`src/data/socketdb.ts`). Браузерные IndexedDB и localStorage на webOS 4 упираются в квоту — новые данные туда не пишутся. Программа — файлом на канал в корзинах `prog2/<источник>/<ab>/<канал>/`, пачки дописываются в `.ndjson`, в конце загрузки канал собирается в один `.epg` — по gzip-куску на сутки с оглавлением в начале (`service/progfiles.js`). Браузер не держит программу канала целиком: `Repo.range` просит у `/prog?s=&x=&a=&b=` только нужные сутки (одни сутки — gzip-кусок как есть с `Content-Encoding: gzip`), кэш — куски «канал + сутки» с пределом по числу передач; поиск по программе — в сервисе (`POST /progsearch`). Не держать программу в памяти сервиса и не перезаписывать хранилище целиком. Всё, на что не ссылается ни один плейлист, сервис удаляет сам (`filekv.gc`). Разбор программы — в дочернем процессе (`service/epgrunner.js`). Сервис — ES5 для Node 0.12. Проверка сервиса: `npm run test:service`, а после правок сервиса или разбора программы — на настоящем Node 0.12: `tools/node012-check.js` (там же, откуда взять Node). Синтаксиса ES5 мало: в Node 0.12 `Buffer` ещё не наследник `Uint8Array` (нет `subarray`), нет `Uint8Array.prototype.slice`/`fill`, `String.prototype.startsWith`/`includes`, `Object.assign` — на этом разбор программы падал на webOS 4 («undefined is not a function»).
