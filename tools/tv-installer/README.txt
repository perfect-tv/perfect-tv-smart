Perfect TV — установка на телевизор LG (webOS) с компьютера

Один раз на телевизоре:
  1. В LG Content Store установите приложение «Developer Mode» и войдите в учётную запись
     LG Developer (бесплатно, регистрация на webostv.developer.lge.com).
  2. В Developer Mode включите «Dev Mode Status» (телевизор перезагрузится), затем —
     «Key Server». На экране — IP телевизора и код Passphrase.

Установка:
  1. Компьютер и телевизор — в одной сети, приложение Developer Mode открыто.
  2. Запустите PerfectTV-Installer.exe (файл .ipk лежит рядом — или перетащите .ipk на программу).
  3. Введите IP телевизора и Passphrase. Дальше программа сама: заберёт ключ, скопирует
     пакет, установит и запустит Perfect TV, продлит режим разработчика.

Режим разработчика работает около 50 часов, потом телевизор удаляет установленные так
приложения. Запускайте программу хотя бы раз в два дня — она продлевает срок (или нажмите
«Extend» в Developer Mode).

Если не получается:
  • «телевизор не отвечает» — проверьте IP, сеть и что Key Server включён;
  • «неверный код» — Passphrase меняется: посмотрите актуальный в Developer Mode;
  • Windows может предупредить о неизвестной программе — «Подробнее» → «Выполнить в любом случае».
IP и код запоминаются в tv-installer.json рядом с программой.
